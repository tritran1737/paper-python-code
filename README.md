# Bridge-vs-Voltage-Divider-Sensor-Analysis 


# Python Code for

Efficiency Analysis of Voltage Divider and Wheatstone Bridge Sensor Circuits

This repository contains the Python scripts used to generate the figures presented in the accompanying research paper.

## Contents

figure_4_and_5.py
Generates Figures 4 and 5.

figure6.py
Generates Figure 6.

## Requirements

Python 3.11

numpy

matplotlib

Install using

pip install -r requirements.txt

## Running

python figure_4_and_5.py

python figure6.py
